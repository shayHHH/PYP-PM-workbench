## 二、两角色实际看到的侧栏

侧栏按 `C.navFor(role)` 渲染：整组带 `roles` 限制的分组会被整体隐藏，因此两角色看到的是**结构不同的两棵树**，而不是同一棵树的灰化版本。

### 产品总监：14 个模块 / 41 个子页

```
┌──── 公共模块 ────┐
│ ▣  仪表盘        │
│ ☰  需求管理      │
│ ⬢  版本管理      │
│ ◔  数据分析      │
│ ⇌  项目协同      │
│ ▤  会议纪要      │

│ ◷  工作留痕      │
│ ✓  待办中心      │
│ ◎  上手与数据    │
├──── 产品总监 ────┤
│ ◈  产品规划      │
```

## 四、路由规则

| 形态 | 示例 | 行为 |
|---|---|---|
| 空 hash | `#/` | 落到 `#/dashboard/main` |
| 模块默认页 | `#/requirements` | 自动补上第一个子页 → `#/requirements/pool` |
| 子页面 | `#/requirements/pool` | 标准形态 |
| 子页面 + 实体 | `#/requirements/pool/RQ012` | 渲染子页后自动打开该实体详情 |
| 无权限 | `#/roadmap`（PM 角色） | 渲染无权限说明页 + "切换到产品总监"按钮 |
| 未注册模块 | `#/xxx` | 渲染 404 说明页 + 返回首页按钮 |

**刷新可还原**：hash + localStorage（角色 / 产品线 / 项目 / 筛选 / 保存视图 / 侧栏折叠）共同决定页面状态。

**返回栈**：`Shell` 维护最长 10 条的返回栈，面包屑左侧的 `←` 在栈非空时出现。抽屉不入栈（因为不改 hash）。

## 五、Tab 与面包屑

子页面同时以两种形式呈现，状态同步：

1. **面包屑** `需求管理 › 需求池`——模块名可点击回到模块默认子页。
2. **Tab 条**——置于页头下方，横排该模块全部子页面。仪表盘只有 1 个子页，Tab 条隐藏。

## 六、响应式与折叠

面向大屏办公，`layout.css` 只设两个断点（`@media (max-width:1500px)` 与 `@media (max-width:1320px)`），内容区 `.content` **不设最大宽度**，随视口铺满：

| 视口宽度 | 侧栏 `--sidebar-w` | `.g4` | `.g5` / `.g6` | 顶栏搜索框 |
|---|---|---|---|---|
| > 1500px | 214px | 4 列 | 5 / 6 列 | 正常 |
| 1321–1500px | 214px | 4 列 | **各降为 3 列** | 正常 |
| ≤ 1320px | **190px** | **降为 2 列** | 3 列 | `min-width:160px` |
| < 1180px | 190px | 2 列 | 3 列 | 出现横向滚动条（`tokens.css:101` `body{min-width:1180px}`） |

侧栏还有一个 **56px 图标态**（`.app.mini`，`--sidebar-w-mini`），但它是**手动折叠**、不随视口自动触发：点击顶栏折叠按钮切换，状态持久化于 `pmw.mini`（`06-shell.js:485` `U.save('mini', …)`），刷新后由 `06-shell.js:488` 还原。折叠 / 展开后延时 220ms 触发 `CH.redrawAll()` 重绘全部图表（`06-shell.js:486`）。

> 未做移动端适配——本系统定位为大屏办公后台，`docs/09` 中已将"响应式到手机宽度"列为有意不做的取舍。

## 七、跨模块跳转路径

系统刻意保留了以下跳转，避免模块成为孤岛：

| 起点 | 触发 | 终点 |
|---|---|---|
| 需求池 · 需求详情 | 点击关联版本 | 版本管理 · 版本计划 |
| 版本详情 | 点击需求数 | 需求管理 · 需求池 |
| 变更详情 | "查看关联需求" | 需求管理 · 需求池 |
| 进度跟踪 · 甘特 | 点击任务条 | 任务管理 · 任务详情 |
| 资源协调 · 成员抽屉 | "查看其任务" | 任务管理 · 任务列表 |
| 资源协调 · 跨部门 | 新建协同事项 | 项目协同 · 跨部门事项（同一数据源） |
| 会议详情 · Action | 点击 Action | 待办中心 · 我的待办 |
| 风险台账 | 点击关联项目 | 进度跟踪 · 甘特图 |
| 全局搜索 ⌘K | 回车 | 对应实体所在页 + 详情抽屉 |

**图表下钻的默认语义是"回填当前页筛选条件"而非跳页**，以保持用户上下文不丢失；只有明确指向其他模块的图表（如首页的产品线进度条）才做跨模块跳转。
