# 产品管理工作台 · Product Management Workbench

一套面向 **产品总监** 与 **项目经理** 的本地 Web 管理后台。

**同一份数据、同一套设计系统、一个开关切换两种视角。**

---

## 快速开始

**双击 `index.html`** 即可。无需 Node、无需 npm、无需构建、无需联网。

第一次打开会弹一个欢迎说明，读完点「开始上手」进入上手清单，跟着做即可。

> 最小可用宽度 1180px，推荐 1440×900 以上。面向大屏办公，不做移动端适配。

---

## 开箱是一个空库

**这不是演示 demo，是给你自己用的工具。里面一条业务数据都没有，全部由你自己录。**

- 28 个业务集合，其中 27 个初始是空数组，没有任何预置内容
- 唯一的例外是成员表 `members`，里面预置「你自己」一条（名字先叫「我」，在「组织与我」里填了真名会同步改过来）—— 否则所有负责人下拉框都是空的，一条业务数据都建不出来
- 每一次新建 / 编辑 / 删除都**立刻写进浏览器 `localStorage`（键名 `pmw.db`）**，刷新不丢
- 每个空页面显示的不是「暂无数据」，而是「这个模块解决什么问题、你的第一步做什么」

⚠️ **数据只存在这台电脑的这个浏览器里。** 清除浏览器数据、换电脑、换浏览器都会丢。
请定期到「上手与数据 → 数据管理」导出 JSON 备份，换机器时导回来。

### 建立顺序有依赖

产品线 → 项目 → 成员 → 需求 / 任务 → 版本。

跳着建不会报错，但下拉框会是空的（还没有产品线时去建项目，「所属产品线」就没得选）。上手清单就是按这个顺序排的：**共定义 9 步，按角色过滤后总监 8 步、PM 6 步**，完成状态由实际数据量自动推导，不用手动打钩。

---

## 它是什么

不是 Figma 画板，是**可运行的前端产品本身**：

- 21 个模块 / 59 个子页面，全部可点可用
- 真实的 hash 路由、面包屑、详情页返回栈
- 11 个纯 SVG 自绘图表函数（折线/面积、柱/堆叠/组合、环形、漏斗、横向排行、流转阶梯、热力、甘特、发布时间线、迷你走势、进度环），带 tooltip / 图例开关 / 点击下钻
- 真实的排序、分页、勾选、批量操作、拖拽看板、表单校验
- CSV / Word / JSON 导出与浏览器打印均可用
- localStorage 记住角色、项目、产品线、侧栏状态、筛选与保存视图

技术形态：**原生 HTML + 原生 JS（IIFE 挂 window）+ 原生 CSS，零依赖零构建。**

## 双角色

右上角开关一点，五件事同时发生：

| | 产品总监 | 项目经理 |
|---|---|---|
| 强调色 | 靛蓝 `#4f46e5` | 青 `#0e7490` |
| 数据口径 | 产品线（多项目聚合） | 当前单项目 |
| 可见模块 | 公共 10 + 战略 4 = **14** | 公共 10 + 执行 7 = **17** |
| 可见子页 | **41** | **46** |
| 首页编排 | 体检式：全局健康度 | 报警式：4 张卡会变红 |
| 关注 | 规划、节奏、经营、风险 | 计划、任务、阻塞、交付 |

**底层数据一个字节都不变。** 切角色只改变视图编排、默认排序、可见范围与统计口径 —— 全程不调用 `DATA.save()`。

登录身份不是内置的虚构人物，就是**你自己**：在「上手与数据 → 上手引导 → 组织与我」里填组织名与你的姓名，顶栏与所有「负责人 / 创建人」字段会同步更新。

### 模块清单

**公共 10 个** — 仪表盘、需求管理、版本管理、数据分析、项目协同、会议纪要、风险预警、工作留痕、待办中心、上手与数据

**总监增强 4 个** — 产品规划、用户反馈、团队管理、经营复盘

**PM 增强 7 个** — 项目计划、任务管理、进度跟踪、资源协调、需求变更、交付管理、周报月报

> 其中「上手与数据」不承载任何业务实体，是实现时补的第 21 个模块（原始需求里列的是 20 个）。理由与移除方式见 [需求对账表 §5.4](docs/00-需求对账表.md)。

## 第一次上手

完整动线见 [09-高保真原型说明 §4.1](docs/09-高保真原型说明.md)，约 20 分钟，做完就有真数据可看。最短路径：

1. **上手与数据 → 上手引导 → 组织与我** —— 填组织名和你的姓名
2. **建第一条产品线** —— 顶栏「＋新建」，或直接点清单上那一步的按钮
3. **建第一个项目** —— 勾上「标准阶段」会自动生成阶段与里程碑
4. **把常打交道的人录进成员表** —— 否则所有负责人下拉框只有你一个人
5. **录几条需求、排一个版本** —— 到这一步首页和图表就不再是空的了
6. **导出 JSON 备份** —— 数据管理页一键导出，养成习惯

## 关键设计取舍

- **角色差异只在编排层**，不在组件层，也不在数据层
- **规则集中在 `01-config.js`** —— 改一处配置，21 个模块同步生效
- **口径收敛只在 `S.scopeFilter` 一处** —— 而不是散在 59 个页面各写各的过滤
- **只有 `02b-data.js` 碰 localStorage** —— 换成真后端时只需改这一个文件
- **角色主题只用 CSS 变量** —— 零 JS 参与，零闪烁
- **图表自绘不用图表库** —— 零依赖、可离线、视觉语言完全可控
- **不预置任何业务数据** —— 宁可空着让引导层教你怎么填，也不塞假数据
- **明确不做**：移动端适配、深色模式、骨架屏、渐变、图标字体、数字滚动动画
